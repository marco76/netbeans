Which mapping operator?

OperatorWhen new work arrivesTypical intent
switchMapCancel previous inner subscriptionLatest search result
concatMapQueue and process in orderOrdered saves
mergeMapRun concurrentlyIndependent requests
exhaustMapIgnore while busyPrevent overlapping submits

Example: each inner emits its letter 3 frames after subscription and completes after 4. mergeMap uses unlimited concurrency here. | means completion.
